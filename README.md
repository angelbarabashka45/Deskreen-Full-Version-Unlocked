## Main Features
<a id="main-features"></a>

### Core Functionality
- **Screen Mirroring** — Easily extend your desktop by creating a link from your PC. Simply paste it into the browser on your secondary device to begin mirroring instantly.
- **Application Window Selection** — Choose to mirror a single application's window, making it ideal for presentations or focused data analysis without distractions.
- **No Installation Required on Secondary Device** — Only the primary device needs the Deskreen application, while secondary devices can connect through any web browser.
- **Wi-Fi Network Compatibility** — All devices must be connected to the same Wi-Fi network, simplifying the setup process.
- **Cross-Device Functionality** — Use any device, including tablets and smartphones, as a secondary screen, providing flexibility in how you work.
